## Pilih jenis dokumen
Template Request Form dapat memiliki dokumen bawaan **mandatory** atau **optional**. Setiap pengajuan mendapat salinan sendiri; file template tidak diubah.

Pilihan upload:
- **Supporting document** untuk lampiran pendukung.
- **sign document or dynamic text** untuk dokumen yang disiapkan melalui editor versi Request Form.

Dokumen tanda tangan mendukung PDF maksimal **30 MB**. Gunakan **Document Sign Editor versi Request Form**, bukan editor standalone, agar Actor terhubung dengan workflow.

## Siapkan melalui editor
<Steps>
<Step title="Pilih Actor dan mode">
Tetapkan **Digital Only** atau **Visual Signature** untuk Actor penanda tangan. Digital Only mencatat persetujuan tanpa gambar tanda tangan. Visual Signature memerlukan posisi signature pada PDF.
</Step>
<Step title="Tambahkan field">
Tempatkan text, multiline, number, date/place, checkbox atau signature. Field dapat memakai nilai statis dari designer, mapping Form Builder, input manual pemohon, API Data Source, atau Actor yang bertanggung jawab sesuai jenis field.
</Step>
<Step title="Periksa sumber nilai">
Field pemohon yang tidak dipetakan ke form muncul sebagai input tersendiri pada area dokumen. API fields harus selesai diuji dan dipetakan. Field milik Actor tetap diisi oleh Actor tersebut; signature tidak boleh digantikan dengan data API.
</Step>
<Step title="Simpan dan pasang">
Pilih **Save & attach to form**. Periksa dokumen telah siap sebelum Submit. Versi form, workflow, desain dokumen dan nilai persiapannya dikunci pada pengajuan.
</Step>
</Steps>

Mode default Actor pada Canvas digunakan saat menyiapkan dokumen baru. Dokumen tersimpan mempertahankan mode serta pemetaannya. Cabang workflow yang tidak dijalankan tidak otomatis menjadi penanda tangan.

## Draft, review, dan revisi
Simpan draft bila persiapan belum selesai, lalu lanjutkan dari **My Requests**. Save draft tidak memulai approval atau memakai Kredit. Submit ditolak bila persiapan dokumen wajib belum valid.

Approver memeriksa versi dokumen, mengisi field yang ditugaskan, lalu memberi konfirmasi. Komentar dan anotasi bukan persetujuan tanda tangan. User internal dapat memilih My Signature, QR Sign, atau tanda tangan manual sesuai mode.

Jika dokumen diubah pada revisi, siapkan dan tinjau ulang versi tersebut sebelum Resubmit. Bukti lama tetap merujuk ke versi lama.

## Kredit
Satu pengajuan workflow menggunakan **1 Kredit**, ditambah **1 Kredit untuk setiap dokumen tanda tangan berbeda**. Dua dokumen tanda tangan dan beberapa Supporting document memakai **3 Kredit**. Lampiran pendukung tidak menambah Kredit tanda tangan.

Dokumen dengan isi asli sama dihitung sekali dalam siklus request tersebut; isi asli berbeda pada revisi dapat menambah satu Kredit. Kredit tidak cukup membatalkan submit. Sandbox tidak memakai Kredit Production.

## Hasil dan akses
Halaman bukti mencatat identitas, tindakan, waktu, dan hash versi dokumen. Mengubah PDF final dapat membuat pemeriksaan integritas tidak cocok. Seal visual DekaSign bukan sertifikasi pihak ketiga.

Izin dokumen tetap diperiksa untuk pemohon, approver, dan Owner. Role Owner/Admin tidak otomatis membuka setiap file privat. Lihat [API Data Source](/guides/document-data), [Request Form Templates](/guides/request-form-templates), dan [Verify Document](/guides/verify-document).
