## Buat dokumen atau gunakan template
Buka **Operations → Document Sign**, pilih buat baru atau template yang dapat diakses. Unggah PDF sumber maksimal **30 MB**. Owner/Admin juga mengelola template melalui **Create Design → Document Sign template**.

Pada editor gunakan Signers dan Field palette, lalu pilih field untuk mengatur Properties. Zoom, Fit, Pan, pindah halaman, resize, Undo/Redo dan preview membantu memeriksa PDF.

## Mode signature dan sumber nilai
**Digital Only** merekam persetujuan dan bukti signing tanpa gambar tanda tangan. **Visual Signature** menempatkan signature di area PDF yang dirancang. Pastikan slot/field ditugaskan ke penerima yang benar.

Pilih nilai tetap dari designer, input Sender, input penerima atau **API Data Source**. Text, multiline, angka, checkbox dan date/place mengikuti tipe field. Nilai tetap diatur di editor; nilai Sender disiapkan sebelum pengiriman.

## Save as template dan berbagi
Setiap pengguna dapat **Save as template** untuk template pribadinya. Owner/Admin mempunyai tindakan berbagi template ke semua pengguna atau pengguna tertentu. Akses template tidak berarti dapat menandatangani atas nama penerima.

## Prepare, Fetch, Preview dan Send
Pilih penerima internal atau eksternal, isi data Sender dan batas waktu. Default expiry adalah **3 days**; periksa deadline sebelum mengirim. Jika API Data Source aktif, isi parameter yang diminta dan Fetch, lalu periksa hasil mapping.

Buka preview PDF terisi, periksa halaman/field, nama/email penerima dan expiry, lalu konfirmasi pengiriman. Perubahan data/template memerlukan preview baru. Lihat [API Data Source](/guides/document-data).

## Penerima dan hasil
Penerima membuka undangan, memverifikasi identitas sesuai alur, membaca dokumen, mengisi field miliknya dan mencentang consent. **Finish signing** berada di panel kanan di bawah konfirmasi. Untuk menolak, isi reason lalu pilih Decline.

User internal dapat memakai [My Signature](/guides/my-signature), QR Sign atau menggambar manual pada signing visual. Satu penerima Signed belum berarti seluruh paket Completed.

Pantau Active packages dan Completed history. PDF final memiliki bukti integritas DekaSign dan dapat diverifikasi melalui Verify document. Bukti DekaSign bukan klaim segel elektronik tersertifikasi atau trusted timestamp pihak ketiga. Bagikan dokumen selesai kepada pengguna internal sesuai akses, atau tambahkan ke Secure Document Sharing untuk alur eksternal yang memerlukannya.
