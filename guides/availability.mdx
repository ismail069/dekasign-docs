## Fitur aplikasi
Panduan mencakup Form Builder, Categories, Request Form Templates, Workflow Canvas, approval serial/paralel ALL/ANY, Actor eksternal, revisi, delegasi, Document Sign, Secure Document Sharing, My Signature, Organization Hierarchy, Access Profiles, Operation Task, My Projects, Contract Lifecycle, Workflow Wizard, dan laporan Owner serta Team Queue.

Ketersediaan tindakan mengikuti role, kategori, izin dokumen, status langganan, serta versi workflow. Contoh desain tidak memberi akses ke data pengguna lain. Periksa setup melalui [panduan Owner](/guides/owner-setup).

## API dan provider
API Sandbox digunakan untuk pengujian. API Production memerlukan paket berbayar aktif, aplikasi/key Production dan cakupan yang diizinkan. Dukungan katalog, submit, signing, attachment dan revisi mengikuti konfigurasi yang tersedia; jangan menganggap setiap operasi Sandbox otomatis tersedia di Production. API manajemen desain yang belum didukung tetap terbatas pada Sandbox.

Channel custom membutuhkan kredensial provider dan test yang berhasil. Accepted tidak berarti delivered/read. Pembayaran aktif setelah hasil provider diverifikasi; halaman redirect saja bukan bukti pembayaran berhasil.

## Koneksi yang perlu disiapkan
[Google Drive](/guides/google-drive), [Calendar organisasi](/guides/google-calendar), [Slack](/guides/slack), [impor HRIS/ERP](/guides/employee-import), dan [n8n](/integrations/n8n) memerlukan setup sesuai kebutuhan. Google login, Drive, dan Calendar memiliki izin terpisah. Untuk kebutuhan SSO enterprise atau konektor lain, periksa cakupan yang tersedia dengan Support.

Bukti integritas DekaSign tidak menyatakan segel elektronik bersertifikat, sertifikat signer pihak ketiga, trusted timestamp, atau verifikasi KYC eksternal. Pilih metode yang sesuai kebutuhan transaksi Anda.

## Bantuan
Bila tampilan atau tindakan berbeda, catat referensi proses, waktu dan pesan error. Hubungi support@dekasign.com tanpa membagikan OTP, password, API key atau link privat.
