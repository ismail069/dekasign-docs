## Siapkan sesi
Buat sesi, atur penerima, masa berlaku, dan keamanan. Unggah file, periksa kebijakan global atau override per file, lalu tinjau dampak penerima dan pemakaian Process sebelum aktivasi.

Satu sesi mempunyai **6 slot file aktif**, dipakai bersama oleh pengirim dan seluruh penerima. File biasa maksimal **25 MB**, ZIP maksimal **40 MB**, memakai MB biner. Menghapus file membebaskan slot; audit dan hubungan file tetap dipertahankan.

## Akses dan upload penerima
Penerima membuka undangan dan melakukan verifikasi. Email adalah default; WhatsApp atau kedua kanal hanya dipakai bila dikonfigurasi dan tersedia. Audience, expiry, revocation, dan izin per file tetap diperiksa. Perubahan versi/kebijakan file dapat memerlukan verifikasi ulang.

Owner/Admin organisasi tidak otomatis mendapat akses ke sesi privat account lain. Logo tenant dapat tampil di halaman eksternal; footer **Powered by DekaSign** mempertahankan identitas platform.

Penerima dapat mengunggah ketika slot kosong dan kebijakan mengizinkan. File masuk privat untuk pengirim dan pengunggah. Pengirim harus melakukan republication eksplisit untuk membagikan salinannya kepada penerima lain.

## Hasil tanda tangan basah
Pengirim menambahkan instruksi tanda tangan basah pada sumber. Penerima menandatangani, memindai, lalu mengunggah PDF/gambar melalui tindakan balasan file tersebut. Scan terhubung ke original pada thread yang sama dan menggunakan satu slot aktif. Ini berbeda dari signing melalui Document Sign.

## Catatan dan anotasi
Preview yang mendukungnya menyediakan note, pin, area, highlight, ellipse, arrow, dan freehand. Pilih **Save private draft**, lalu **Post** saat siap. Draft hanya terlihat oleh penulis. Thread penerima ditujukan kepada pengirim dan penulis; pengirim dapat memilih audience yang sudah mempunyai akses file.

Reply, resolve/reopen, dan riwayat memakai versi untuk mencegah tab lama menimpa perubahan baru. Anotasi terikat pada sumber, versi, dan representasi preview. Anotasi spasial XLSX belum tersedia; gunakan file note. Anchor native sheet/cell dan visual historis masih terpisah.

## Unduh dan audit
**Download** mengikuti izin file. Preview-only tidak menyajikan original sebagai fallback. PDF, Office dan gambar dapat diunduh sebagai salinan visual ber-watermark. ZIP dikecualikan dari watermark, termasuk pratinjau isinya; unduhan ZIP menyajikan arsip asli jika izin mengizinkan. Verifikasi, batas unduh, masa akses dan audit tetap berlaku. Salinan visual bukan original yang dapat diedit atau ekspor anotasi.

Laporan membedakan preview, download yang dilayani, upload, dan konfirmasi penerimaan. Preview/download tetap dicatat bila penerima lupa melakukan konfirmasi. Penyajian file bukan bukti bahwa isinya telah dibaca atau disetujui.


## Ekspor laporan sesi
Pada versi terbaru yang diuji lokal, pemilik sesi saat ini dapat memilih **Laporan JSON** atau **Aktivitas CSV** pada **Laporan peristiwa**. Langganan aktif dan sesi workspace terverifikasi wajib. JSON memuat metadata sesi/file, aktivitas terfilter serta catatan/riwayat yang boleh terlihat. CSV berisi aktivitas terfilter dan melindungi dari formula spreadsheet. Keduanya tidak memuat file asli, URL storage atau draft privat milik pihak lain.

Ekspor dibatasi dan diaudit. Persempit filter aktivitas atau gunakan CSV jika JSON terlalu besar. Laporan data ini terpisah dari PDF tinjauan beranotasi. Ketersediaan production mengikuti versi yang telah dirilis.

## Unduh PDF tinjauan beranotasi

Versi terbaru yang diuji lokal menambahkan **Izinkan ekspor PDF tinjauan (PDF/gambar saja)** pada kebijakan sesi dan file. Izin ini nonaktif sampai diaktifkan secara eksplisit. Izin unduh dan catatan juga wajib. Pada preview yang diizinkan, pemilik saat ini atau penerima terverifikasi dapat memilih **Unduh PDF tinjauan**.

Salinan menggabungkan PDF/gambar saat ini, tanda visual bernomor, catatan diposting/diselesaikan dan reply yang boleh terlihat. Draft privat tidak disertakan. Anchor sumber/versi/preview harus tetap sesuai. Watermark kebijakan diterapkan pada salinan tinjauan; original tetap utuh.

Satu ekspor dibatasi 20 halaman sumber dan keluaran 25 MB. Teks yang tidak didukung, anchor stale atau halaman/ukuran berlebih menolak seluruh ekspor. ZIP, Office dan representasi historis tidak disertakan. Salinan membantu peninjauan, bukan bukti signing. Salinan dibuat sementara, dicatat dalam audit download/ekspor dan memakai jatah unduh, tanpa Process tambahan. Ekspor native Office/sel belum selesai.

## Pemakaian dan keamanan
Aktivasi untuk satu penerima memakai **1 Process**; setiap penerima tambahan menambah satu Process. Undangan ulang eksplisit yang berhasil setelah revocation menambah satu Process baru. Retry transport dan kirim ulang OTP bukan reinvitation. File, anotasi, dan preview tidak menambah Process per dokumen seperti [dokumen approval yang ditandatangani](/guides/workflow-signing).

Isolasi account/tenant tetap berlaku. Operator server/database/storage saat ini masih berpotensi membaca konten. Enkripsi dengan kunci di luar kendali operator dan dormant-data retention otomatis masih direncanakan. Langganan tidak aktif tidak otomatis menghapus dokumen.

Kebijakan retensi yang disetujui memisahkan file dari data akun:

| Organisasi | File upload, termasuk PDF final bertanda tangan | Akun, konfigurasi, workflow dan template |
|---|---|---|
| Trial yang terverifikasi belum pernah membayar | 60 hari setelah trial berakhir | Empat bulan kalender setelah trial berakhir |
| Organisasi berbayar | Empat bulan kalender setelah paket berbayar berakhir | Satu tahun kalender setelah paket berbayar berakhir |

Audit dan bukti verifikasi dokumen tetap tersimpan tanpa batas waktu; file PDF final ikut dihapus bersama file lain. Setiap tenggat file/akun memiliki notifikasi satu bulan kalender, 14 hari dan tiga hari sebelumnya. Renewal terverifikasi membatalkan jadwal lama. Riwayat/notifikasi yang belum lengkap atau hold aktif menghalangi penghapusan. Worker notifikasi dan purge file terkontrol sudah diuji lokal; switch production tetap nonaktif. Penghapusan akun, expiry backup dan penerimaan R2 nyata masih terbuka.

Rancangan dan pemeriksa konfigurasi kunci tenant telah disiapkan. Infrastruktur dan pemrosesan terlindungi belum tersedia, sehingga konfigurasi tersebut belum membuat operator tidak dapat membaca dokumen.
