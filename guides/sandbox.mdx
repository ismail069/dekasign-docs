## Mulai simulasi
Buka Workflow Canvas dan pilih **Run sandbox**. Periksa nama serta versi workflow aktif. Pilih pemohon simulasi dan isi nilai form sesuai key serta tipe field; gunakan **Load sample values** sebagai titik awal.

Pilih **Start New Run** untuk membuat simulasi. Ini tidak mengirim request nyata, menandatangani PDF produksi, mengirim pesan nyata, atau memakai Kredit Production.

## Baca Execution Trace
Trace menampilkan nama node/element/step, ID, event, dan waktu sehingga Anda dapat mencocokkannya dengan desain. Panel trace dapat di-scroll. Gunakan navigasi kembali ke Canvas workflow yang sedang diuji; di Canvas, cari ID untuk memilih, menyorot, dan memfokuskan step.

## Uji keputusan dan kondisi
Pada Actor aktif, pilih identitas simulasi dan keputusan. Isi alasan sebelum **Request Revision** atau **Reject**. Pesan validasi muncul pada area tindakan yang terkait.

Uji setiap output Rule dan optional Condition Operation Task memakai contoh sesuai kebutuhan Anda. Sertakan nilai batas, kondisi tidak terpenuhi, manager tidak valid, serta staf tidak tersedia. Nilai contoh bukan aturan bisnis bawaan.

## Waktu, revisi, dan Operation Task
Gunakan waktu virtual untuk Wait, SLA, dan pengingat. Untuk revisi, ubah data simulasi lalu Resubmit; periksa tujuan kembali dan batas revisi. Untuk Operation Task, periksa kategori, all/specific staff, penugasan tunggal, dan hasil simulasi.

Waktu virtual bukan bukti pengiriman provider atau eksekusi worker pada jam nyata. Setelah desain berubah, ulangi Validate dan simulasi yang relevan sebelum Publish. Catat versi, ID step, input, expected result, serta hasil aktual saat melaporkan masalah.
