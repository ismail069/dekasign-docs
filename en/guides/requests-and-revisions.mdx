## Submit a Request Form
Open **Operations → My Requests**, then choose an authorized category and Request Form. Check its version, complete required fields and tables, and review documents before **Submit**. Tables support [CSV import](/en/guides/table-csv). **Save draft** does not begin approval.

Mandatory default documents must remain included. Optional documents can be removed according to template settings. Add a **Supporting document** or **sign document or dynamic text**. Complete manual inputs, form mappings, or API Fetch before saving dynamic document preparation. See [workflow documents](/en/guides/workflow-signing).

If the workflow uses Direct Manager, the requester's manager must be configured, active, and authorized—including when the requester is Owner. Self-approval is prohibited.

## Details and status
Request details separate **Detail Pengajuan, Alur & Riwayat** from **Document Proposal**. Review Actor/step, status, approver name, job title, update time, and pinned version. Parallel routes show ALL/ANY requirements. History describes steps actually executed.

Add the request to [My Projects](/en/guides/my-projects) from its detail page. Grouping references does not change access permissions.

## Approver review
Open **My Works → My Approvals**. **Form** contains submitted values and comments. **Documents** separates signing and supporting documents, with annotations beside the preview. The changes view helps compare revisions where available; **Activity** contains action history.

Review documents, complete your assigned fields, and check confirmation before signing. Comments or annotations alone do not approve a request. **Approve**, **Reject**, and **Request Revision** are separate decisions.

## Revise
1. Open the same request when its status requires revision.
2. Read the reason and annotations, then update permitted fields/attachments.
3. Prepare changed documents again where required.
4. Review the latest version and choose **Resubmit**.

Routing follows the configured Revision/Loop path and limits. Final rejection does not automatically reopen editing.

## After approval
Approved does not mean operational follow-up or payment is complete. Review Operation Task status and result data when used. Completed requests can export a PDF with form information, highlighted status, signed document references, and a DekaSign validation page.
