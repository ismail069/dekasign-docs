---
title: "Form Builder"
description: "Design fields, tables, CSV references, validation and consistent request forms."
---

Owner/Admin opens **Create Design → Form Builder**. Use a standard form or create one. Add fields, select them on the canvas and set labels, help text, required values, validation and options in Properties. Test Preview before saving.

## Fields and conditions
Choose text/multiline, integer/decimal, options, checkboxes, date/date-time, files and dynamic tables. Conditions use available fields and type-appropriate operators. Field keys are used by mappings and APIs; changing a label does not change its key.

## Tables and CSV import
A table supports **10 columns**, **500 rows** or a lower designer limit, and 128 KB of table data. Use it for purchasing items, expenses, overtime or event requirements. Required values, numeric ranges and dropdown options remain validated.

Requesters can download **CSV template**, fill many rows and choose **Import CSV**. Review mapping, preview and Append/Replace before Apply. Import does not submit the form. See [CSV table import](/en/guides/table-csv).

## CSV reference data
Text fields can obtain values from a CSV reference list through a searchable dropdown or popup. Designers select the value column; requesters search a code/name and select it. This differs from table-row import.

## Documents
Upload fields accept the formats offered by the UI, with a 30 MB/file request/Document Sign limit. Choose **Supporting document** or **sign document or dynamic text**. Signing documents use the Request Form Document Sign Editor with workflow Actor mappings.

Configure mandatory/optional default documents, static values, manual requester inputs, form mappings and API Data Source in [Request Form Templates](/en/guides/request-form-templates). Every request receives its own copies.

## From form to request
Save the form, select it in Workflow Engines, check routing, Validate/test Sandbox and Publish. Then create a Request Form Template from the published workflow and grant requester category/form access. Editing the form does not change pinned versions on running requests.
