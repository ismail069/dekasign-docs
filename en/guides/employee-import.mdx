---
title: "Import employees from HRIS or ERP"
description: "Fetch employee data, review mapping, and select who to import."
---

As Owner, open **Management → Integrations → HRIS/ERP** or **Import employees** in User management. Ask your HRIS or ERP administrator for an HTTPS endpoint and API access.

1. **Connect the source.** Set a stable source ID. Enter the endpoint and the provided authentication details, then test the connection.
2. **Choose the employee list.** Select the response array and configure pagination.
3. **Map data and access.** Choose employee ID, name, email, and relevant attributes. Preserve string IDs from the source. Select available roles, Access Profiles, or queues.
4. **Review the preview.** Check invitations, links, updates, and conflicts. Select the rows you want before confirming.
5. **Check results.** New employees receive invitations and complete account verification. Identity conflicts or an expired preview require another review.

Source job titles and departments are metadata. Select DekaSign grants explicitly. Review employment status and direct manager changes through your organization's processes. [Accounts and roles](/en/guides/accounts-and-roles)
