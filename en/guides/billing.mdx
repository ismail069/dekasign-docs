Open **Management → Plans & billing** for the workspace plan, usage, and invoices. Use [Pricing](https://dekasign.com/en/pricing) to compare prices, seats, credits, storage, and add-ons.

## When are credits used?

| Activity | Credits |
| --- | --- |
| Submit a new approval request | 1 per request |
| Document that requires signing in a workflow | 1 extra per chargeable document in the request cycle |
| Supporting attachment | 0 signing credits |
| Create a contract record or renewal draft | 1 per new record |
| Edit a contract | 0 creation credits |
| Activate Secure Document Sharing | 1 for the session and first recipient, then 1 per additional recipient |

For example, one request with two documents to sign and one supporting attachment uses **3 credits**. Review or signing linked to a contract follows the rules for that activity. If submission is interrupted, check history before creating a new record.

## Trial and payment

The 30-day trial includes 50 total credits, 5 seats, and 2 GB of storage. There is no automatic charge. Included paid-plan credits renew monthly without rollover. Check billing for top-up, storage, and seat terms.

Before checkout, check the period, currency, and total cost. After paying, check **Plans & billing**. If payment is pending, wait for confirmation or ask Support to check the invoice before paying again.
