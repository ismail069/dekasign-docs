## Personal calendar

Open an active contract you can access. Choose **Download calendar (.ics)** and import the file into your calendar. The file contains a snapshot of the dates. If they change, review the old events and import again if needed. Alarm behavior depends on the calendar app.

## Organization Google Calendar

1. Create a secondary shared calendar for contracts. Set its time zone and choose who can view it.
2. Ask your Google administrator to grant the organization service account permission to edit events on that calendar. Copy the Calendar ID from **Integrate calendar**.
3. As Owner, open **Management → Integrations → Google Calendar · Organization**. Enter the Calendar ID and select **Verify & enable**.
4. On an eligible [contract](/en/guides/contract-lifecycle), enable sync and check its status.

Shared events contain generic titles and dates. DekaSign reminder emails follow the recipients configured on the contract. If **Verify & enable** fails, check that the service account has effective write access and you selected the correct calendar.
