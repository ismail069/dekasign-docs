---
title: "My Projects"
description: "Organize your requests, Document Sign packages and Secure Document Sharing sessions into private project collections."
---

**My Works → My Projects** groups requests and documents belonging to the same work. For example, an Office Renovation project can contain a purchase request, a Document Sign contract package, and a Secure Document Sharing session for vendor quotations.

A project is a private collection. Adding an item does not share documents, transfer ownership, or change its original workflow and permissions.

## Create and edit a project

![My Projects detail in the DekaSign application with synthetic QA project data](/images/app/my-projects-detail.png)

1. Open **My Projects** and select **Create project**.
2. Enter a recognizable project name and description.
3. Save. Its detail page contains **My Request**, **Document Sign**, and **Secure Document Sharing** sections.
4. Select **Edit project** to update its name or description.

Search the My Projects list by name or description. Each card shows the count of items you can still access in each section. Use **Previous** and **Next** to navigate pages.

## Add an existing item

<Steps>
  <Step title="Open your request or document">
    Open a submitted request, a sent standalone Document Sign package, or a created/sent Secure Document Sharing session. Drafts cannot be added.
  </Step>
  <Step title="Select Add to My Project">
    Select **Add to My Project**. In the popup, choose **Existing project** to search and select a project, or **New project** to create one there.
  </Step>
  <Step title="Confirm the project">
    Select **Add to project** or **Create & add**. After success, the item's **My Project** link opens that collection.
  </Step>
</Steps>

An item can belong to only one of your projects. If it is already included, use the displayed project link; adding does not create a second copy.

## View items and status

Open a project and select **My Request**, **Document Sign**, or **Secure Document Sharing**. The list shows each item's name/reference, status and creation time. Select its name or **View details** to open the original page and your permitted actions.

Project status follows the original item. Grouping items does not complete approval, signing or operational work. Times follow the organization timezone.

## Ownership and access

- Eligible requests are your own non-Draft submissions.
- Document Sign uses standalone packages you own or hold through an authorized handover; documents signed inside a request remain accessible through that request.
- Secure Document Sharing follows current session ownership/custody.
- Owner and Admin roles do not automatically expose another user's private projects or files.

If ownership or access changes, an item may disappear from its former project. A project does not retain revoked access or keep a hidden document copy.

If the add button is missing or adding fails, check the non-Draft status, item ownership, active organization, and whether the item already belongs to a project. Reload if it changed in another tab.
