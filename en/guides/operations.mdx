## Notification bell
Click the top-bar bell for available events: approval tasks ready, revision requests, completed workflows, and completed signing packages. Reading a notification does not make a decision or complete a signature.

## History and tables
Use the filters, search, and pagination available on each page. Access Activity loads 200 records by default and shows 50 rows per page; date/time filters follow organization timezone. Request history shows visited steps and related versions; do not interpret every possible node as completed work.

## Common issues
| Symptom | Check |
|---|---|
| Missing form/card | Active category, published workflow, request/form grants. |
| Approver missing from dropdown | Active membership, category grant, validity, node policy. |
| Resubmit denied | Needs revision status, current draft/task versions, required corrections. |
| Document preview fails | Complete Sender fields, content fits, correct recipients, unchanged token/version. |
| Signing denied | Identity, consent, recipient-owned inputs, deadline, document version. |
| Email/WhatsApp fails | Active/tested channel, destination mapping, provider template, credentials, quota. |
| API 503 sandbox disabled | The host has not enabled sandbox API access; a production header is not a fix. |

## Support
Record the time, page, process reference, node/step ID where available, expected result, and error code/message. Redact credentials and sensitive data from screenshots. Never share token links/OTPs. Contact support@dekasign.com. Support availability is not a promise of a specific response-time SLA.

## Plans and billing
Plans/quotas follow the agreed offer. Trials do not automatically charge you. Billing documentation does not prove live checkout is enabled. Do not repeat a payment merely because a browser redirect has not changed; check status and reconciliation.
